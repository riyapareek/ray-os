Ray OS is a web-based operating system that works in a browser. It is designed with a pink theme, making it look soft, clean, and attractive. It feels like a real desktop where you can open and use different apps.

Features:
 Calculator – for basic calculations
 Notes – to write and save ideas
 To-Do List – to manage daily tasks
 Snake Game – a fun game to play
 Draw App – to draw and be creative
 Wallpaper – to change the background
About Ray OS:

Ray OS is simple and easy to use. It helps in both learning and fun. You can do small tasks, stay organized, and also enjoy games in one place.

In short: Ray OS is a mini operating system on the web with useful tools and a cool pink design.
